# How to Get the 3 WhatsApp Keys — Simple Step-by-Step

Follow these in order. It's all free. Takes about 15 minutes.
At the end you'll have 3 things to paste into the app.

---

## Before you start
Have these ready:
- A Facebook login (personal is fine)
- The tuition centre's business name

---

## Step 1 — Open the developer site
1. Go to **https://developers.facebook.com**
2. Click **Log In** (top right) and sign in with Facebook.
3. If it's your first time, click **Get Started** and accept the terms.
   (This just registers you as a developer — free, no approval needed.)

## Step 2 — Create an app
1. Click **My Apps** (top right).
2. Click the green **Create App** button.
3. **App name:** type `AccelLearn Invoicing`.
4. It may ask "What do you want to do?" — choose the option that mentions
   **Messaging / WhatsApp** (labelled "Other" then "Business" on some screens).
5. Click **Create App**. Enter your Facebook password if asked.

## Step 3 — Add WhatsApp to the app
1. You're now on the app dashboard. Scroll to find a list of products.
2. Find **WhatsApp** and click **Set up** next to it.
3. If asked to select a Business Portfolio, pick the centre's one (or create
   one with the centre's name). Click **Continue**.

## Step 4 — Copy the 3 keys
1. In the left menu, click **WhatsApp**, then **API Setup**
   (sometimes called "Quickstart" or "Getting Started").
2. You'll see a page with the info we need. Copy these **three** items:

   🔑 **Key 1 — Temporary access token**
   A long string near the top. There's a **Copy** button next to it.

   🔑 **Key 2 — Phone number ID**
   A long *number* in the "From" section.
   (⚠️ NOT the phone number itself — the one *labelled* "Phone number ID".)

   🔑 **Key 3 — WhatsApp Business Account ID**
   Just below Key 2, another long number.

3. Paste all three into a note (or send them to me) clearly labelled 1, 2, 3.

**Easiest option:** just take a **screenshot of the whole API Setup page** and
send it — all three keys are on it.

## Step 5 — (Optional) Add your phone for testing
Still on the API Setup page, in the **To** field:
1. Click **Manage phone number list** → **Add phone number**.
2. Enter your own mobile number → you'll get a code on WhatsApp → type it in.

This lets us send a test invoice to *your* phone first, before any real parent
gets one.

---

## That's it!
Once I have those 3 keys, I'll put them into the app and send a test invoice to
your phone so you can see exactly what parents will receive.

**Two heads-ups:**
- Key 1 (the token) expires after 24 hours at first. If some time passes,
  just go back to the API Setup page and copy the fresh one — I'll tell you if
  I need it again. (Later we'll make a permanent one that never expires.)
- Nothing is charged during testing. Going live costs a few cents per invoice,
  and we'll set up billing together when we're ready.
